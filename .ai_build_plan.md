# Zero-Play-Store - AI Build Blueprint

A Flutter-based offline-first application designed as an alternative app distribution platform.

## Goal
Maintain a robust offline-first mobile application with a focus on PDF editing and document management features, avoiding any Google Play Store dependency.

## Tech Stack
- **Framework:** Flutter (Dart).
- **Package Manager:** pnpm (for tooling scripts).
- **Architecture:** Monorepo (pnpm-workspace.yaml).
- **CI:** GitHub Actions (.github/).

## AI Guidelines
1. Core Flutter app logic lives in lib/. Follow established Flutter clean architecture patterns.
2. Scripts in scripts/ are for build automation — validate before modifying.
3. Do not add Google Play Services dependencies; the app is intentionally Play Store-free.

5. Keep .ai_build_plan.md in the repository for ongoing architectural guidance.
