## 🌟 Overview
**Zero-Play-Store** is a privacy-respecting, offline-first Flutter application that operates entirely without Google Play Store dependencies. Focused on document management and PDF editing, it gives users full control over their data.

## 🚀 Key Features
- 🔌 **Fully Offline:** Core functionality works without any internet connection.
- 📄 **PDF Management:** Advanced document viewing and editing capabilities.
- 🛡️ **Privacy First:** Zero reliance on Google Play Services or external telemetry.
- 🏗️ **Monorepo Architecture:** Organized with pnpm workspace for scalable tooling.

## 🛠️ Technology Stack
- **Mobile Framework:** Flutter / Dart
- **Build Tooling:** pnpm (workspace)
- **CI/CD:** GitHub Actions
